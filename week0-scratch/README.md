This is the first Scratch project I have done for the CS50 Project Challenge!

It is a short animated story about two students in a class having a conversation and dynamic movement about sharing a stationery item, or to be specific, a pen/pencil. 
It is a pretty straightforward storyline, but while implementing it on my own, I covered a lot of Scratch features. 

## Concepts practiced
- Sprites and backdrops
- Dialogue and sequencing
- Broadcast messages
- smooth animation
- Sound effects

## What I'd add next
- Make it more interactive, i.e., game-like with user interaction
- more dynamics
- implement a bigger storyline
- Even smoother animations
